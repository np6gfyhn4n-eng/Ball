رحلة صناعة كرة القدم ⚽

موقع تعريفي تفاعلي يعرض رحلة صانع كرات قدم، من اختيار المواد الخام حتى تصبح الكرة جاهزة للمباراة.

شكل الموقع

أقسام الموقع

  • التعريف بالصانع: نبذة عن الصانع ومهنته.
  • المواد والأدوات: ما يستخدمه الصانع في عمله.
  • مراحل الصناعة: التصميم، القص، الطباعة، التجميع، التركيب الداخلي، النفخ والاختبار.
  • الصور والفيديو: أماكن مخصصة لوسائطك.
  • فحص الجودة: المحيط، الوزن، الضغط، الارتداد.
  • صمّم كرتك: اختيار ألوان الكرة أو تصاميم جاهزة.
  • اختبر معلوماتك: ٦ أسئلة مع نتيجة نهائية.

الملفات

index.html   هيكل الصفحة
readme.html  صفحة عن المشروع
style.css    التصميم
script.js    رسم الكرة والمصمم والاختبار
README.md    ملف GitHub

التشغيل

افتح index.html في المتصفح مباشرة، ولا يحتاج إلى تثبيت أي شيء.

النشر على GitHub Pages

  1. ارفع الملفات إلى مستودع جديد.
  2. من Settings ثم Pages اختر الفرع main والمجلد / (root).
  3. سيظهر رابط موقعك خلال دقائق، وتجد هذه الصفحة على /readme.html.

التخصيص

  • غيّر اسم الصانع ونبذته في قسم الصانع داخل index.html.
  • أضف صورك في مجلد media واستبدل مربعات الصور بوسم <img>.
  • أضف الفيديو داخل وسم <video>.
  • عدّل أسئلة الاختبار من مصفوفة questions في script.js.

أرقام فحص الجودة تقريبية لكرة مقاس ٥، ويُفضّل التأكد منها من مصدر رسمي.
